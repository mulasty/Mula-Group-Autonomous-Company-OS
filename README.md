# MulaGroup Autonomous Company OS

## Mission
Build a practical Autonomous Company OS for Mula Group that turns business decisions into structured execution through agents, workflows, and documented delivery.

## Operating Model: GitHub-first
- **Source of truth:** GitHub repository files.
- **Secondary workspace:** Google Drive (notes and draft artifacts only).
- All formal specifications, workflow definitions, and backlog records must live in this repository.

## Current Status
This repository is initialized with documentation-first structure for workflow design, backlog control, prompt management, and orchestration planning.

## Core Pipeline
Decision → Specification → Backlog → GitHub Issue → Coding Agent → Pull Request → Review → Documentation → Next Task
